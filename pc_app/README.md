# 量房仪 PC 服务

产品运行时，HTTP 网页只在 PC 上提供。ESP32 首次绑定时开启固定配网热点，绑定完成后作为 STA 自动连接电脑热点，并主动向 PC 推送实时 JPEG、遥测和扫描文件。

## 固定端口

- PC 网页：TCP `8000`
- 设备数据接收：TCP `8765`
- 设备首次绑定：TCP `8766`（仅设备配网热点阶段）

Windows 防火墙首次提示时，应允许 Python 访问“专用网络”。

## 首次绑定

1. 在 PC 运行：

   ```powershell
   python pc_app\server.py
   ```

   也可以运行 `pc_app\start.ps1`；停止隐藏服务时运行 `pc_app\stop.ps1`。

2. 设备没有绑定信息时会开启：

   - SSID：`LASER-METER-SETUP`
   - 密码：`12345678`

   以上是设备出厂配网凭据，仅用于首次绑定；公开部署或多人使用前应评估并更换默认密码。电脑移动热点的示例脚本同样使用演示密码 `12345678`，请按实际网络安全要求调整。

3. PC 连接该热点。系统提示“无互联网”属于正常现象。

   Windows 也可以直接运行：

   ```powershell
   powershell -ExecutionPolicy Bypass -File pc_app\connect_device.ps1
   ```
4. 浏览器仍访问本机 `http://127.0.0.1:8000/`，点击“绑定设备”。
5. 填写随后要由 PC 开启的移动热点名称和密码。PC 服务会通过 TCP `192.168.4.1:8766` 将信息写入设备 NVS。
6. PC 断开设备配网热点，开启刚才填写的移动热点。

   本机 Windows 10/11 可直接运行固定热点脚本（需要已有以太网或其他上网连接）：

   ```powershell
   powershell -ExecutionPolicy Bypass -File pc_app\start_hotspot.ps1
   ```

7. 设备自动连接电脑，PC 页面顶栏显示“设备在线”。

PC 本机访问 `http://127.0.0.1:8000/`；连接到 `LASER-PC` 的手机访问
`http://192.168.137.1:8000/`。

## 测量

进入设备“平面图”并开始扫描后：

- 设备屏幕只显示扫描状态，不显示相机画面；
- PC 页面显示设备实时视频、距离和 IMU 角度；
- 扫描结束保存后，`scan_XXXXXX.csv` 自动上传到 `pc_app/data/<device_id>/`；
- SD 卡原文件始终保留，上传失败不会丢失测量结果。

## 扫描处理与继续绘图

PC 收到扫描 CSV 后会同时保留原始点和处理结果，不会用自动结果覆盖原始测量：

- 蓝色：原始点云和测量射线；
- 青色：邻域中值门禁后保留的点，红色是删除的孤立径向跳点；
- 绿色：连续点约束下的 RANSAC 主墙线及相邻墙线交点；
- 橙色：被主墙线跨过的短凹口，作为家具、门窗或遮挡候选保留。

处理参数和墙线残差会随 `/api/scan` 一起返回。墙线不足、扫描角度不完整或墙角无法可靠相交时，网页只允许人工核对，不会自动生成正式墙体。

继续绘图操作：

1. 在“最近扫描”的历史下拉框选择完整的一圈扫描并载入；
2. 分别开关原始点云、中值滤波、RANSAC 墙线和遮挡图层进行核对；
3. 点击“采用墙线并编辑”，绿色拟合线才会批量转成正式墙体；
4. 使用“选择”拖动墙体端点，或切换“绘墙”继续补画，再放置门、窗和插座；
5. 保存项目会记录扫描文件路径和自动墙线的拟合来源，重新加载后可恢复核对底图。

旧项目若存在墙角中心点接近但墙面留缝，可点击顶部“闭合墙角”。它会把相邻墙轴延伸到交点并保留已经放置的门、窗和插座。尺寸、遮挡文字及构件符号采用屏幕固定尺寸，整图缩放后仍保持可读和可点击。

## Windows 移动热点

设备会使用 DHCP 返回的网关地址连接 PC，不依赖写死的 `192.168.137.1`。热点名称和密码必须与首次绑定时完全一致。
